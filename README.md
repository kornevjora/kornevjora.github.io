# Гайды

Бесплатная библиотека по дизайну, UX и ИИ: https://kornevjora.github.io/

Этот репозиторий содержит проверенный публичный выпуск сайта. Архивы site-*.zip включают только готовые HTML, стили, скрипты, иллюстрации и открытые учебные материалы. Данные бота и настройки доступа сюда не входят.

GitHub Actions проверяет SHA256SUMS, распаковывает выпуск и публикует его через GitHub Pages. Для обновления замените архивы и SHA256SUMS одним коммитом. Исходный проект и инструкция сборки находятся у автора.

Условия использования материалов: https://kornevjora.github.io/terms/
